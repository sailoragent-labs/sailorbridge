# Instal aplikasi

Sebaiknya instal SailorBridge sebagai aplikasi web di ponsel atau komputer Anda. Aplikasi ini punya ikon sendiri dan terbuka seperti aplikasi biasa, di jendela tersendiri tanpa tab dan kolom alamat browser yang biasa Anda lihat.

## iPhone atau iPad dengan Safari

1. Buka [aplikasi](https://app.sailorbridge.com) di Safari.
2. Ketuk **Bagikan** (kotak dengan panah ke atas). Jika tombolnya tidak terlihat, buka menu halaman Safari terlebih dahulu.
3. Pilih **Tambahkan ke Layar Utama**. Jika ada pilihan **Buka sebagai App Web**, aktifkan, lalu ketuk **Tambah**. Buka SailorBridge dari ikonnya di Layar Utama.

Di iPhone dengan iOS 16.4 atau lebih baru, Anda hanya dapat menerima notifikasi push dari aplikasi yang terpasang di Layar Utama. Buka aplikasi, aktifkan **Notifikasi** di pengaturan, lalu beri izin saat diminta.

## Android dengan Chrome

1. Buka [aplikasi](https://app.sailorbridge.com) di Chrome.
2. Buka menu tiga titik, pilih **Instal dan buat pintasan**, lalu **Instal**. Jika menu langsung menawarkan opsi untuk menginstal aplikasi atau menambahkannya ke layar utama, Anda juga dapat menginstal dari sana.
3. Konfirmasikan penginstalan, lalu buka SailorBridge dari ikonnya.

## Chrome atau Edge di komputer

1. Buka [aplikasi](https://app.sailorbridge.com) di Chrome atau Edge.
2. Klik ikon instal di kolom alamat, atau gunakan menu browser untuk menginstal SailorBridge sebagai aplikasi.
3. Konfirmasikan penginstalan dan buka SailorBridge dari ikon aplikasi.

## Safari di Mac

1. Buka [aplikasi](https://app.sailorbridge.com) di Safari pada macOS Sonoma 14 atau lebih baru.
2. Pilih **File → Tambahkan ke Dock**.
3. Klik **Tambahkan**, lalu buka SailorBridge dari Dock.

## Setelah menginstal

Anda mungkin perlu masuk lagi saat pertama kali membuka aplikasi. Jika aplikasi yang terpasang memakai data browser tersendiri, seperti saat dipasang lewat Safari, SailorBridge memperlakukannya sebagai browser baru untuk akun Anda. Lihat [Masuk dan konfirmasikan browser baru](account-and-security.md#masuk-dan-konfirmasikan-browser-baru). Jika diminta menambahkan kunci browser ini, lihat [Periksa aktivitas dan kunci perangkat](account-and-security.md#periksa-aktivitas-dan-kunci-perangkat).

Untuk menghapus aplikasi, hapus dari Layar Utama di iPhone atau iPad, atau uninstal melalui setelan aplikasi Android, Chrome, atau Edge. Jika dipasang melalui Safari di Mac, hapus aplikasi dari folder Aplikasi di folder utama Anda.
