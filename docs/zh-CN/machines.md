# 机器

机器是连接到你账号的电脑，用来运行团队小组长或领取任务。你在每台机器上安装 `sail`，然后在浏览器中批准。关闭终端后，后台服务仍会保持连接。

## 安装并配对机器

1. 使用由你控制的 Linux x64 或 macOS（arm64 或 x64）机器。安装 Git。要聊天或跑任务，请装好 Claude Code 或 Codex，在这台机器上登录自己的引擎账号。可以先完成配对，再登录引擎。
2. 在应用里打开 **机器**，再打开 **配对新机器**。把显示的安装命令复制到想连接的机器上的终端。在任意目录均可运行。它会安装 `sail`，启动配对，并显示一个有效期为 10 分钟的 8 位配对码。
3. 在浏览器的 **配对码** 下输入该码，选择 **配对**。对照终端核对机器名和 **钥匙短码**。首次配对时，请先阅读提示后再接受。Agent 可以用运行 `sail` 的操作系统用户的权限读取、更改和删除文件，使用凭证及连接网络。需要隔离时，使用专用机器或容器。
4. 选择 **批准机器**。机器获取凭证并启动服务时，请保持连接。当 **机器** 显示 **在线** 且终端确认连接后，可选择 **配置账号** 或 **建团**。[建团](teams.md)

## 检查连接或配对更多机器

在 **机器** 中打开一台机器，查看其名称、平台、**最后在线**、**配对于** 和 **客户端版本**。你可以在这里改名，以便区分机器。在机器本身运行 `sail host status`，查看配对、连接和服务状态，并找到本机日志。

要使用另一台电脑，请再次打开 **配对新机器**，在那台电脑上运行显示的命令。等它上线后，添加到团队并在那里设置项目文件夹。一台机器可供多个团队使用。每件任务由所属团队的一台符合条件的机器运行。[管理团队的机器](teams.md)

## 更新或修复安装

自动更新默认开启。验证更新后，服务会重启并继续处理本机工作。已完成的步骤会保留，被中断的本机步骤可能重新运行。要手动更新，请在机器上运行 `sail upgrade`。它会说明是安装了更新、已经是最新版，还是遇到了错误。运行 `sail --version` 查看已安装的版本。

服务需要恢复时，运行 `sail login`。在同一地址，它会用现有凭证重新安装并重启服务。如果凭证被拒绝且机器仍有登记，就会启动修复配对。浏览器会显示 **已有的机器重新配对**，并标出要替换的机器。核对详情后批准新配对码。机器会保留原来的团队。收到新凭证时，用于密码恢复的配对日期会重新计算。

## 停用机器或卸载

要在整个账号中停用一台机器，请打开 **机器** 中该机器行的菜单，选择 **删除** 并确认。机器的凭证会被撤销，它会退出所属团队，并在收到通知时停止工作。已连接时会立即收到通知，否则在下次连接时收到。本机工作副本会保留。要再次使用它，请在机器上运行 `sail login`，批准新的配对，并将它添加到需要它的团队。

要从电脑上卸载，先保存 SailorBridge 工作副本中需要的成果。在该机器上运行 `sail uninstall`。命令会停止服务，并删除 `sail`、服务定义、安装程序添加的 shell 路径项和整个 `~/.sailorbridge/` 目录。这包括凭证、账号登记、日志、本机聊天记录、工作副本和 `sail` 的备份。你自己的项目目录和引擎登录目录会保留。要重新安装，请使用 **配对新机器** 页面上的命令。

## 遇到问题时

- 如果配对提示没有 Git，请安装 Git，然后运行 `sail login` 继续。引擎未登录时，可在开始聊天或跑任务之前，另行运行 `claude login` 或 `codex login`。
- 配对码过期时，运行 `sail login` 获取新码。如果机器名或 **钥匙短码** 不一致，请选择 **取消配对**，并检查目标机器上的终端。如果批准后机器在 10 分钟内仍未连接，先运行 `sail host status`，再运行 `sail login` 重新连接。
- 如果机器意外离线，运行 `sail host status` 检查网络和服务。默认离线判定窗口为 90 秒。只有连续离线 10 分钟才会出现离线通知，重新上线后通知消失。
- 更新失败时，打开该机器查看原因，并以安装 `sail` 的用户运行显示的修复命令。如果本机备份无法使用，请用配对页上的安装命令。
- 如果机器报告服务器身份变了，它会拒绝连接。在机器上运行 `sail host status --trust` 查看保存的指纹。如果身份变更符合预期，运行 `sail login`，在终端检查新指纹，然后批准新的配对。
- 如果 `sail login` 报告 `origin_mismatch`，请先按上述步骤卸载，再切换地址。然后复制目标应用 **机器** 页的安装命令。无法读取本机配对凭证时，也需要卸载并重新配对。
- 如果 `sail uninstall` 报告服务无法确认停用，本机文件已被删除。打开 **机器**，在那里停用该机器条目。
