# SailorBridge 设置指南

## 1. 准备机器

选择一台自己控制的 Linux x64 或 macOS（arm64 或 x64）机器。安装 Git，以及 Claude Code 或 Codex 中的一个。用自己的账号登录引擎，选好要交给团队的项目目录。

**核对** — 运行 `git --version` 和所选引擎的 `claude --version` 或 `codex --version`，两者都应显示版本。引擎已装但没登录时，在这台机器上运行 `claude login` 或 `codex login`。可以先配对，在聊天或跑任务前完成引擎登录即可。

## 2. 在浏览器里注册

打开[应用](https://app.sailorbridge.com)，选择**去注册**。初次体验时，输入一个可用且显示为免费的数字船长号，设置密码，完成年龄和服务条款确认。

**核对** — 进入应用后可以打开**机器**页。

## 3. 运行安装命令

从**机器**进入**配对新机器**页。复制页面上的那一条安装命令，在第 1 步选定的机器上执行。它会安装 `sail`，自动开始配对。

**核对** — 终端显示 8 位配对码和剩余时间。码已过期时，运行 `sail login` 取新码。

- **已配对到同一地址？** 运行 `sail host status`。已连接就继续第 5 步。要恢复同一地址的服务，运行 `sail login`，它会用现有凭证重启服务。
- **地址不对（`origin_mismatch`）？** 要切换地址，先运行 `sail uninstall`，再到目标应用的机器页复制安装命令并重新执行。卸载会删除 SailorBridge 的本地数据，包括它创建的代码副本。

## 4. 批准机器

在浏览器的配对页输入配对码，选择**配对**。核对页面上的机器名和详细信息。阅读首次配对时关于 `sail` 运行用户权限的提示，勾选同意后选择**批准机器**。

**核对** — 等**机器**页显示**在线**。终端也会提示机器已配对、在线。

## 5. 建团

选择**建团**。填写团队名称，选中在线机器，在**项目目录**里输入这台机器上的绝对路径。目录不存在时，SailorBridge 会在首次使用时创建。在**成果去向**里，保留默认的**自动合**会把改动合进远端主线。选择**推活分支**则把每件任务推到单独的分支，留待审核。然后建团。

**核对** — 新团队里显示你选的机器，状态为**在线**。

## 6. 发第一句话

进入团队的**聊天**，问一句“我们在哪个项目目录里工作？”

**核对** — **小组长**在同一间聊天室回复。

## 7. 完成第一件任务

在团队聊天室发送 `/agent 数一下项目目录顶层有几个文件，把数量告诉我。` 打开 **⋯ → 任务列表** 查看进度。

**核对** — 任务状态为**完成**。打开交付单，查看文件数量。
