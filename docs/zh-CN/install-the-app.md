# 安装应用

建议在手机或电脑上将 SailorBridge 安装为网页应用。它有独立图标，像原生应用一样在自己的窗口中打开，没有浏览器常用的标签栏和地址栏。

## iPhone 或 iPad 上的 Safari 浏览器

1. 在 Safari 浏览器中打开[应用](https://app.sailorbridge.com)。
2. 轻点**分享**按钮（带向上箭头的方框）。如果看不到，先打开 Safari 浏览器的页面菜单。
3. 选择**添加到主屏幕**。如果看到**作为网页 App 打开**选项，请打开它，再轻点**添加**。然后从主屏幕图标打开 SailorBridge。

在 iOS 16.4 或更高版本的 iPhone 上，只有安装到主屏幕的 SailorBridge 应用才能发送推送通知。打开应用，在设置中开启**通知**，并在弹出提示时允许通知。

## Android 上的 Chrome

1. 在 Chrome 中打开[应用](https://app.sailorbridge.com)。
2. 打开三点菜单，选择**安装并创建快捷方式**，再选择**安装**。如果菜单直接提供安装应用或添加到主屏幕的选项，也可以从那里安装。
3. 确认安装，然后从图标打开 SailorBridge。

## 电脑上的 Chrome 或 Edge

1. 在 Chrome 或 Edge 中打开[应用](https://app.sailorbridge.com)。
2. 点击地址栏中的安装图标，或在浏览器菜单中选择将 SailorBridge 安装为应用。
3. 确认安装，然后从应用图标打开 SailorBridge。

## Mac 上的 Safari 浏览器

1. 在运行 macOS Sonoma 14 或更高版本的 Mac 上，用 Safari 浏览器打开[应用](https://app.sailorbridge.com)。
2. 选取**文件 → 添加到程序坞**。
3. 点按**添加**，然后从程序坞打开 SailorBridge。

## 安装后

首次打开应用时，可能需要重新登录。使用 Safari 浏览器安装的网页应用有独立的浏览器数据。应用使用独立数据时，SailorBridge 会把它视为此账号的新浏览器。参见[登录并确认新浏览器](account-and-security.md#登录并确认新浏览器)。如果系统提示添加这个浏览器的钥匙，参见[查看活动和设备密钥](account-and-security.md#查看活动和设备密钥)。

要移除应用，在 iPhone 或 iPad 的主屏幕上删除，在 Android 的应用设置或 Chrome、Edge 中卸载，使用 Mac 上的 Safari 安装时则从个人文件夹下的“应用程序”文件夹中删除。
