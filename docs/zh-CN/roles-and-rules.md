# 角色与规则

每个团队都有一个 **小组长**。你可以在团队聊天室与它交谈。它能回答问题、运行简短命令，并把较长的工作交给流程。工人在团队机器上执行流程中的步骤。你可以在项目仓库里给引擎写长期指令。目前没有角色编辑器或规则库。

## 把合适的工作交给团队

打开团队的 **聊天**。可以问“我们在哪个分支上？”**小组长** 会检查团队目录并在对话中回复。要快速检查团队中的另一台机器，请输入 `@`，选择机器，再说明要检查什么。你会收到结果摘要。

需要交付并审查的工作，可以这样请求：“更新设置说明并请人审查。”**小组长** 提出后台流程时，请阅读卡片上的任务。选择 **对,做** 将任务加入队列，或选择 **不是这样** 说明要改什么。打开 **任务列表** 查看工人的执行步骤。工人需要你决定时，**小组长** 会先检查团队已有信息，仍需要你的回答时才在聊天中询问。

## 为引擎设置长期指令

把整个项目都适用的指令写在仓库里，Codex 用 `AGENTS.md`，Claude Code 用 `CLAUDE.md`。例如，记下交付改动前要运行的命令。引擎在该仓库工作时会读取自己的指令文件。要让团队跨任务记住某个事实，也可以在聊天中请它记下。[团队记忆](team-memory.md)

## 中断后继续对话

在同一个团队聊天室发送下一条消息。长时间中断、更换引擎或迁移到另一台机器后，**小组长** 可能会启动新的引擎会话。它会接续使用团队保存的摘要、近期消息、团队记忆和未完成的任务。如果看到 **会话整理中…**，你仍可发送消息。**小组长** 完成摘要后会回答。

## 遇到问题时

- 如果缺少旧对话里的细节，在下一条消息中给出任务编号、决定内容或相关文件。新会话会获取最近 20 条消息，并在有摘要时获取摘要。
- 如果之前对话中的错误指令一直沿用，选择 **清空聊天**，核对团队名称后确认。之前的消息会从聊天视图中隐藏，下次会话不会带上旧摘要。如果指令来自仓库中的文件或团队记忆，请在那里更正。
- 如果 **小组长** 超时，请拆成较小的步骤再问，或把较长的活作为任务发送。[命令](commands.md)
