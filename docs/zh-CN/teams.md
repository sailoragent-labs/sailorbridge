# 团队

团队为一个项目提供独立的 **小组长** 聊天、任务队列、团队记忆和至少一台机器。你可以拥有多个团队，也可以让一台机器服务于多个团队。只有你能查看和更改自己团队的设置。

## 为项目建团

1. 配对将运行小组长的机器。当它显示 **在线** 时，在配对页选择 **建团**。也可以打开 **团队**，选择 **建团** 开始。[配对机器](machines.md)
2. 输入 **团队名**，再选择该机器。你可以从这台机器提供的选项中选定 **头像**，以及小组长的账号、模型和推理强度，也可以使用默认设置。
3. 在 **项目目录** 中填写所选机器上以 `/` 开头的绝对路径。如果已在某个仓库中工作，使用其本地目录。要使用现有的远端仓库，请先在该机器上克隆仓库并配置其 Git 凭证。SailorBridge 会识别仓库的主分支。
4. 选择 **成果去向**，再选择 **建团**。团队会列出这台机器。打开 **聊天** 与小组长交谈。[使用团队聊天](chat.md)

团队首次使用该路径时，会打开现有文件夹；不存在时会创建。对于已有文件的普通文件夹，系统会初始化 Git 并保存初始快照。如果文件夹下一层有多个 Git 仓库，告诉小组长你指的是哪个。每件任务只在一个仓库工作。跨仓库的工作要拆成不同的任务。

## 选择改动的去向

在 **团队** 中打开你的团队，进入 **团队详情**。可以在那里更改 **项目目录** 或 **成果去向**。更改从机器下次领取任务时起生效。

| 成果去向 | 在哪里找到任务的提交 |
| --- | --- |
| **自动合**（默认） | 机器尝试推送到远端主分支，再快进本地的主分支。如果远端主分支已有新提交，或远端要求审查，请查看交付单。如果交付单列出了任务分支，请在远端合并该分支。 |
| **推活分支** | 每件任务推送自己的 `sb/<job>` 分支，供你审查和合并。其他任务从项目的主分支开始。 |

每台机器使用仓库自身的 Git 远端和凭证。开始任务前会获取远端主分支，并在可能时快进本地副本。如果推送失败，打开任务的 **交付单** 查看失败原因、本地分支、提交和推送命令。[查找任务交付单](jobs.md)

## 添加、迁移或移除机器

在 **团队详情** 中打开 **机器列表**，用加号按钮 **加一台机器**。选择已配对机器，然后选择 **同团目录**，或在 **项目文件夹** 中填写该机器自己的绝对路径。以后可以编辑该路径。符合条件且有空位的机器现在就能从同一队列领取任务。

要从该团队移除机器，选中它并确认 **移出这个团**。它将停止从此队列领取新任务。如果移除或停用了标有 **小组长在这台** 的机器，剩余机器中最早加入团队的一台会接任小组长。团队最后一台机器不能移除，请先添加替代机器。

## 设置团队如何领取任务

回到 **团队详情**，更改此团队运行工作的方式。

- 在 **任务设置** 中，**派发** 控制新工作。选择 **已暂停派发** 会保留队列中的任务，正在运行的任务可继续。选择 **正常派发** 后机器可以重新领取排队任务。
- **同时跑几件** 默认为 **不限**，因此使用账号的并发上限。选择 **设个数** 可限制该团队同时运行的任务数。调低数字时，限制随当前运行的任务完成而生效。
- 在 **小组长模型** 下选择账号，再选择模型和可用的推理强度。账号会连同所在机器一起列出。选择团队中另一台机器上的账号，会让小组长从下一条消息起移到那里。它会继续使用同一份对话摘要和团队记忆。正在运行的任务留在各自的机器上。
- 对于工人，请为每种难度和提供商选择首选模型和可用的推理强度。**恢复默认** 将某个选择恢复为团队默认值。可以在 **账号列表** 中把账号限定为写、审或小组长专用。[引擎账号与限速](engine-accounts-and-pacing.md)

## 解散团队

打开 **团队详情**，选择 **解散团队**，核对将结束多少个 Agent 会话，然后输入团队名称确认。解散后无法恢复。未结束的任务会取消，定时事件会删除，团队会从列表和聊天入口移除。该团队未处理的 Agent 会话请求和正在进行的会话都会结束。每位参与者保留自己的会话历史。机器仍与你的账号配对。

## 遇到问题时

- 没有机器可选时，建团请用 **去配对机器**，添加机器时请用 **配对一台新机器**。如果机器已停用，请重新配对后再添加。
- 如果任务或聊天报告无法创建目录，请检查尝试使用该路径的机器。该路径上已有文件、缺少写权限或磁盘只读都可能阻止创建。选择 **去团队设置改目录**，为该机器输入可写目录。
- 如果建团时小组长的账号或模型已不可用，请从刷新后的列表中重新选择。建团后如果排队的工作一直等待，请在任务详情中阅读 **为什么没在跑**，查看是派发、上限还是账号导致的。
