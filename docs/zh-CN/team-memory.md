# 团队记忆

团队记忆保存决定、约定和修正，供 **小组长** 和工人在后续任务中使用。每条记忆都有标题、正文、来源和编号，例如 `#6`。每条记忆属于一个团队，其他团队和好友无法浏览。

## 记录值得保留的内容

在团队聊天室说清要记住什么、何时适用。例如，“记住，安装示例应放在设置指南里。修改安装命令时遵照这条约定。”**小组长** 会告诉你记录了什么。打开团队聊天室的 **更多操作** 菜单，选择 **团队记忆** 查看条目。打开标题可阅读全文并查看最后修改的人。

## 查找条目并在聊天中使用

打开 **搜索**，它位于 **团队记忆** 中。输入标题或正文中的词语。文本结果必须匹配所有词语，第一页还最多可显示 3 条语义相近的条目。置顶条目在普通列表中排在最前面。

知道编号时，搜索 `#6` 只会找到条目 6。搜索 `6` 也会找到文本匹配项。打开条目，选择 **去聊天室**。输入框会填上 `/memory #6`。附上问题或更正再发送。

## 编辑、置顶、锁定或删除条目

- 打开条目，修改 **正文** 后选择 **保存**。**历史** 显示最近 10 个版本。对于可能变化的事实，检查 **观察时点** 和 **过期**。**已过期** 条目仍可阅读，请核对其中的建议是否仍然适用。
- 打开 **置顶**，会把指令加进提供给 **小组长** 和工人的材料。条目会显示该团队的置顶用量。所有置顶条目的标题和正文合计最多可用 8 KiB。
- 要让只有你能修改或删除条目，请打开 **不可更改**。仅置顶时，Agent 仍可编辑条目。你可以在网页上编辑锁定的条目。
- 选择 **删除** 并确认，即可永久移除条目。它的编号不会重新使用。

## 整理团队记忆

在团队聊天室发送 `/memory-tidy`。任务会检查条目，标记值得保留的内容，合并相关条目，并删除以后用不到的条目。打开任务的 **交付单**，了解它做了什么以及哪些事项仍需你决定。如果任务提出删除或合并锁定条目，这些条目仍会保留。

有条目需要检查时，每个团队滚动 24 小时内最多自动整理一次。如果只想按请求或按定时事件运行，打开 **团队流程**，选择 `memory-tidy`，关闭 **自动整理**。

## 遇到问题时

- 置顶后如会超过 8 KiB，则无法置顶。先取消另一条置顶或缩短已置顶的文本，再试一次。
- 如果你操作期间有人编辑了条目，会显示最新正文。先阅读再重新应用你的修正。
- 如果两次更新使用同一标题，同一作者的更正可以直接生效。否则，可由确认级别更高的更新决定，或在同级别时采用观察时间更新的一条。如果需要作决定，条目会显示 **有待裁的冲突** 并保留当前正文。打开条目、核对事实，再保存正确的表述。锁定条目需要你决定。
- 如果 **小组长** 报告记忆未保存，请再说明一次要记住的内容。如果 Agent 因条目锁定而无法修改，请在 **团队记忆** 中亲自更改。
