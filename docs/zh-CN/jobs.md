# 任务

一次流程运行就是一件任务。每个团队的机器共用一个队列。你可以在聊天中交办任务，按编号查询进度，打开交付单查看产出和仍需你处理的事项。

## 将工作加入队列

在团队聊天室发送流程名称和任务内容，例如 `/agent Count the files at the top level of this project and report the count.`。任务进入队列，符合条件的机器有空位时会领取。该机器在自己的工作副本中运行任务。

如果 **小组长** 在对话中提出工作，阅读提议后选择 **对,做** 将它加入队列。计划包含多件任务时，请先读清单再选择 **全部放进任务队列**。**修改计划** 可让你说明改动，**暂不执行** 则暂不将这批任务加入队列。接受后，每件任务都有自己的编号。[选择流程](flows-and-scheduled-events.md)

## 查找任务并查看状态

打开团队聊天室的 ⋯ 菜单，选择 **任务列表**，也可以在聊天的任务卡上选择 **看详情**。列表起初显示 **运行中**，之后会记住此浏览器上次使用的筛选条件。选择 **全部** 可包含已结束的任务。可以用任务文本或流程名称搜索，也可以输入带井号的完整编号（如 `#6`），跨筛选条件查找。

| 显示内容 | 含义 |
| --- | --- |
| **排队** | 任务正在等机器领取。下方一行说明原因。如果引用了任务编号，说明它在等那件前置任务。 |
| **运行中** | 已有机器领取任务。打开可查看当前阶段和机器。 |
| **等小组长** 或 **等人** | 小组长会处理能回答的问题。需要你决定时，选择 **去作答** 并在聊天中回答。**等你** 筛选项可查找等你回答的任务。 |
| **完成** | 流程已交付结果。**做完了,检查没过** 表示已有交付，但有检查失败。使用结果前先阅读该项检查。 |
| **未完成** | 流程在交齐要求的内容前停止。查看它停在哪一步、还缺什么。已经产出的工作会保留。 |
| **失败** | 运行因错误结束。打开报告和 **机器的备注** 查看原因。 |
| **已取消** | 任务已停止。仍可在列表中查看该条目。 |

**已暂停** 和 **等额度** 也可能解释任务还在等什么。打开 **为什么没在跑** 查看等待原因和可采取的操作（如有）。

## 查看任务、交付和用量

选择带编号的任务行。**任务详情** 显示状态、**运行** 和 **轮数**。**任务信息** 包括机器、发起人和 **排队**。展开 **分步**，查看已运行的阶段、耗时及所用的引擎和模型。如果有 **质量问题**，其中会显示自审、同伴审查和最后一轮同伴审查的发现。

任务结束时打开 **交付单**。阅读 **改了什么**、**检查**、**审稿意见**、**没核的** 和 **要你定的**。已完成的任务如有检查失败，会优先显示失败项。任务生成提交后，请查看提交去了哪里。机器无法推送时，报告会给出本地分支、提交、原因和可运行的命令。只需报告的任务可以直接交付答案。

打开 **用量** 并展开 **分轮明细**，查看 token 数量和实际使用的模型。用量按提供商、账号和模型记录。交付单中的总计涵盖最近一次机器领取后的用量。排队时间和运行时间分别记录。

## 暂停、更改、停止或继续任务

- 对排队中的任务选择 **暂停**，可阻止机器领取。可以运行时再选择 **恢复**。选择 **现在开始** 可将排队任务移到队首。没有空位时，你可以继续等，也可以明确停止一件正在运行的任务来腾出空位。
- 要修改未结束的任务，在任务中选择 **去聊天室**。系统会填入任务编号。补充新要求并发送。如果小组长提出修改，选择 **对,改**。排队的任务会就地更新说明。正在运行的尝试会停止，任务以同一编号重新排队。
- 要结束任务，选择 **停** 并确认。你主动停止的任务需要收到你的指示才能继续。已结束的任务如果有保存的恢复点和可用工作，在 ⋯ 菜单中选择 **继续**。它沿用同一编号和保留的工作副本或已推送分支。如果继续前修改要求，任务会从头开始。
- 选择 **重做**，可沿用原流程、说明、仓库和选项另排一件任务。新任务会有新编号，旧任务仍可查看。**继续** 不可用时可用此操作。确认 **删除** 后，将永久删除已结束任务的记录。

## 遇到问题时

- 如果整个团队已暂停派发，想让机器重新领取新任务时选择 **恢复派发**。如果团队或账号达到并发上限，任务会在有空位后开始。[团队派发设置](teams.md)
- 如果任务在等你的回答，超过 5 分钟后仍可回复。5 分钟后机器会释放空位。你作答后，原机器一空闲就会继续。
- 如果任务缺少写手或审查者，选择 **去账号**。一台机器必须具备整个任务所需的账号。如果所有候选机器都拒绝，任务失败，备注会列出各台机器的原因。如果在等额度或限速，请查看预估时间。额度恢复或有空位后，工作会继续。[引擎账号与限速](engine-accounts-and-pacing.md)
- 如果机器失联，重新连接后可以继续。如果 30 分钟内未续期，团队中的另一台机器可以领取任务并从头开始。同一件任务失联 3 次后以 **失败** 结束。继续或重做前请检查机器。[检查机器](machines.md)
- 可恢复的系统故障在一件任务的整个运行期间最多可自动继续 10 次。如果任务仍处于结束状态，阅读最后的报告并处理原因，再选择 **继续**（如有）。
