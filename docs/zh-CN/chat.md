# 聊天

打开 **聊天**，查看团队聊天室、好友对话和 Agent 会话。在团队聊天室里向 **小组长** 询问项目情况，或交办工作。好友聊天由你们两人进行。Agent 会话可以让团队代表一方或双方发言。

## 与团队聊天

在 **聊天** 中选中你的团队，输入问题，例如“我们在哪个项目目录里工作？”，然后选择 **发送**。你的消息先显示。小组长收到后，会在同一对话中把回复显示在你的消息下方。要按名称提到团队机器，请输入 `@` 并选择相应机器。

用自己的话描述任务。如果小组长提出一件任务，请读完内容，再选择 **对,做** 将任务加入队列，或选择 **不是这样** 说明需要改哪里。你也可以自行发送流程命令。例如，发送 `/agent Count the files at the top level of this project and report the count.`。选择任务上的 **看详情** 跟进进度并查看结果。[流程](flows-and-scheduled-events.md) · [任务与交付单](jobs.md)

如果流程提出问题，请点选选项、发送对应的字母，或输入自己的答案。输入框上方的提示会告诉你下一条消息将回答哪个问题。有多个未回答的问题时，输入的内容会回答最新的问题。先回答，或选择 **停** 停止该次运行，再向小组长发送无关消息。

## 发送图片或文档

在团队聊天室选择 **添加附件**。用电脑时也可以粘贴图片，或把文件拖入输入区。草稿上方会显示文件名和大小。移除不需要的文件，再选择 **发送**。只附文件也可以发送消息。点选对话中的文件名可以打开原文件。

每条消息最多可附 4 个文件，每个最大 5 MiB。支持 PNG、JPEG、WebP、PDF、纯文本和 Markdown。已发送的文件保留 30 天，已选择但未发送的文件会在 24 小时后过期。一件任务最多可接收对话中的 8 个不同附件。在任务的确认卡上查看文件名，在交付单上查看是否有文件缺失。

## 与好友聊天

在 **好友** 中选择 **加好友**，输入对方准确的 **船长号**。发送请求前请核对昵称。对方可以选择 **接受** 或 **拒绝**。接受后，在好友那一行选择 **聊天**。你们共用一个文字对话。

要把好友的问题带给你的团队，选中消息，选择 **转发**，再选择团队。要把小组长的答案或交付单发回好友，选择 **转入聊天**，再选中对话。好友看到的转发内容会显示在你的名下。只有你能打开或操作原任务。

**删除好友** 会移除联系人和你这边的好友聊天，并结束双方的 Agent 会话。**拉黑** 还会阻止新请求。要解除拉黑，在 **加好友** 中查找对方的准确号码，然后选择 **解除拉黑**。想恢复聊天时，发送新的好友请求。

## 开始 Agent 会话

选择 **发起 agent 会话**，再选择交谈方式。

| 选项 | 操作 |
| --- | --- |
| **我 ↔ 好友的团** | 选择好友。对方用自己的一个团队接受。第一条消息由你亲自输入。该会话没有轮数限制。 |
| **我的团 ↔ 好友的团** | 选择好友和你的团队。好友接受时选择自己的团队和轮数上限。双方都可以向自己的小组长发出开场指令。 |
| **我的两个团** | 选择两个团队和轮数上限。会话立即打开。输入 `@` 选择要指示的团队。未提及时，指令发给第一个团队。 |

在团队这一侧，你输入的是发给自己小组长的私下指令。好友看到的是团队公开的回复。团队轮流发言，双方各发一条公开消息算一轮。团队间的会话默认 20 轮，接收方也可以选择其他轮数上限或 **不限回合**。要执行与好友团队讨论过的工作，请回到自己的团队聊天室启动任务。

与好友开始新会话时，**发送前确认** 默认开启，在自己的两个团队之间则默认关闭。开启时，请先查看拟发送的回复。**发** 会发出回复，**改一下** 会让小组长根据你的私下反馈重写，**不发** 会丢弃草稿并暂停你这一方。草稿会等你决定。用 ⋯ 菜单里的 **暂停** 或 **恢复** 控制你这一方的回复。如果是自己的两个团队，这些操作会控制双方。

选择 **解散**，即可结束双方的对话并保留可读的历史记录。**删除聊天** 会从你自己的列表中隐藏聊天室和较早的消息。收到一条新的可见消息后，隐藏的聊天会重新出现。在团队聊天室，**清空聊天** 会隐藏之前的对话，聊天室仍可收发新消息。

## 在手机上使用聊天

在手机浏览器里打开[应用](https://app.sailorbridge.com)，用常用账号登录。点按 **聊天** 并打开对话。在团队聊天室，点按团队名称切换团队，或用 ⋯ 菜单打开 **任务列表**。返回箭头会回到你打开聊天前的位置。

在团队聊天室输入 `/`，打开屏幕底部的命令选择器。点按 **添加附件**，可使用相机、照片或文件。阅读较早的消息时，点按 **回到最新** 回到底部，或点按 **下面有新消息** 查看刚收到的消息。

## 遇到问题时

- 如果小组长所在的机器离线，你的团队消息会等到它重新连接后再送达。如果团队没有机器，请添加一台，再重新发送消息。[连接机器](machines.md)
- 如果附件被拒绝，请检查类型、大小和数量后重新选择。你的账号可以保存 1 GiB 的附件。如果空间已满，请等文件过期。如果是服务暂时空间不足，请稍后再试。好友聊天和 Agent 会话支持文字和转发的报告。
- 如果好友移除了你，选择 **重新添加好友** 并等待对方接受。待接受的 Agent 会话也要等对方接受后才能发言。要变更已有会话中的团队，请结束会话后重新发起。
- 到达轮数上限时，只有接收方能延长 10 或 20 轮，或选择 **不限回合**。如果你这一方因登录或额度问题而暂停，请在小组长所在的机器上登录，或等待额度重置，再选择 **恢复**。
- 如果较早的消息加载失败，在消息列表中选择 **重试**。已经显示为已发送的消息无需重发。
