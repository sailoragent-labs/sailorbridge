# SailorBridge セットアップガイド

## 1. マシンを準備する

自分が管理する Linux x64 または macOS（arm64、x64）のマシンに、Git と、Claude Code か Codex のどちらかをインストールします。自分のアカウントでエンジンにログインし、チームで使うプロジェクトディレクトリを決めます。

**確認** — `git --version` と、選んだエンジンの `claude --version` または `codex --version` で、それぞれバージョンが表示されます。インストール済みのエンジンに未ログインなら、そのマシンで `claude login` または `codex login` を実行します。先にペアリングを済ませることもできます。チャットや作業を始める前にログインしてください。

## 2. ブラウザーで登録する

[アプリ](https://app.sailorbridge.com)を開いて **登録へ** を選びます。ここでは、使用可能で無料と表示される数字の船長 ID を入力し、パスワードを設定して、年齢と利用規約を確認します。

**確認** — アプリに入り、**マシン** を開けます。

## 3. インストールコマンドを実行する

**マシン** から **新しいマシンをペアリング** を開きます。そこに表示された一つのインストールコマンドをコピーし、手順 1 のマシンで実行します。`sail` がインストールされ、ペアリングが自動で始まります。

**確認** — ターミナルに 8 文字のペアリングコードと残り時間が表示されます。期限が切れたら `sail login` で新しいコードを取得します。

- **同じアドレスでペアリング済みの場合** — `sail host status` で接続済みなら手順 5 に進みます。同じアドレスでサービスを復旧するには `sail login` を実行します。既存の認証情報でサービスが再起動します。
- **アドレスが違う場合（`origin_mismatch`）** — 切り替えるには `sail uninstall` を実行してから、接続したいアプリのマシン画面でインストールコマンドをコピーして実行します。アンインストールすると、作業用コピーを含む SailorBridge のローカルデータが削除されます。

## 4. マシンを承認する

ブラウザーのペアリング画面にコードを入力し、**ペアリング** を選びます。マシン名と **キーコード** をターミナルの表示と照合します。初回は `sail` を実行するユーザーの権限についての説明を読み、同意して **マシンの承認** を選びます。

**確認** — **マシン** で **オンライン** になるまで待ちます。ターミナルにもペアリングと接続の完了が表示されます。

## 5. チームを作成する

**チームを作成** を選びます。チーム名を入力し、オンラインのマシンを選び、**プロジェクトディレクトリ** にそのマシン上の絶対パスを入力します。ディレクトリがなければ初回使用時に作成されます。**成果の送信先** は、リモートのメインブランチに変更を統合するなら既定の **自動マージ**、作業ごとに別のブランチにプッシュしてレビューするなら **ブランチ** を選び、チームを作成します。

**確認** — 新しいチームに選んだマシンが **オンライン** と表示されます。

## 6. 最初のメッセージを送る

チームの **チャット** を開き、「このチームのプロジェクトディレクトリはどこですか？」と尋ねます。

**確認** — 同じチャットで **リーダー** が返信します。

## 7. 最初の作業を完了する

チームのチャットで `/agent プロジェクト直下のファイルを数えて、件数を報告してください。` と送ります。**⋯ → 作業一覧** で進捗を確認します。

**確認** — 作業の状態が **完了** になります。**納品レポート** を開き、ファイルの件数を確認します。
