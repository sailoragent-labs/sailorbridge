# アカウントとセキュリティ

数字の **船長 ID** がログイン名です。ニックネーム、パスワード、ブラウザーを変更しても、アカウントの船長 ID は変わりません。ログインできるうちに、自分で管理するマシンをペアリングしてください。パスワードを忘れた場合は、ペアリング済みのマシンが必要です。

## アカウントを作成する

1. [アプリ](https://app.sailorbridge.com)を開き、**登録へ** を選びます。希望する 3～11 桁の番号を入力します。**すでに主張済み** と表示されたら、別の番号に変更して確認します。
2. その番号について画面に表示される内容を確認します。通常の 6～8 桁の ID と、9～11 桁の ID はすべて無料です。それより短い ID や 8 桁までの特別な番号には買い切り料金がかかります。有料の番号を選んだ場合は、別の端末でも登録を完了できるよう、決済時の **引き換えリンク** を保存します。[料金](https://www.sailorbridge.com/#pricing)
3. パスワードを設定し、確認のために再入力します。用意されているアバターを選ぶか、イニシャルのままにできます。年齢確認を済ませて **利用規約** に同意し、**登録** を選びます。アプリにログインします。[最初のマシンをペアリングする](machines.md)

## ログインして新しいブラウザーを確認する

**サインイン** を選び、**船長 ID** と **パスワード** を入力します。ペアリング済みのマシンがある場合や 2 段階認証を使っている場合、新しいブラウザーでは確認が求められます。2 段階認証を有効にしていると、使い慣れたブラウザーでもログインのたびに確認が必要です。

**本人確認** では、表示される方法のいずれかを使います。

- **認証アプリのコード** を使う場合は、認証アプリに表示されている現在のコードを入力します。
- **マシンのコード** を使う場合は、ペアリング済みのマシンのターミナルで `sail confirm` を実行します。ログイン画面に 8 文字のコードを入力します。
- 画面に 2 桁の数字が表示されたら、すでにログインしている別のブラウザーを開きます。両方の画面の **キーコード** が一致することを確認してから、ログイン画面に表示された 2 桁の数字をタップします。自分が開始したリクエストでなければ、**自分ではない** を選びます。

## プロフィールを設定し、ログインを保護する

**自分** を開きます。**ニックネーム** を設定し、ギャラリーから **アバター** を選べます。**言語** の変更は、次のチャットのターンまたは作業から、画面表示と返信に適用されます。**回答スタイル** では、詳しい説明が欲しい場合は **初心者** を、短い返信が欲しい場合は **上級者** を選びます。

**セキュリティ** から **2段階認証** を開きます。**有効にする** を選び、パスワードを確認して認証アプリで QR コードを読み取ります。現在のコードを入力し、**確認して有効にする** を選びます。解除するときは **2段階認証を無効にする** を選び、パスワードと新しいコードを入力します。

パスワードを変更するには、**現在のパスワード**、**新しいパスワード**、**新しいパスワードを確認します** を **セキュリティ** で入力します。2 段階認証が有効なら、認証アプリのコードも入力します。変更後はこのブラウザーでログインした状態になり、ほかのセッションはログアウトします。

## アクティビティと端末の鍵を確認する

**自分** から **セキュリティ** を開き、**最近のセキュリティ記録** を選びます。直近 90 日間の記録が表示されます。新しいブラウザーからログインに成功すると、自分の操作だったか確認を求められます。**自分です** または **自分ではない** を選びます。確認はブラウザーごとに記録されます。失敗したログインも一覧に表示されますが、承認は求められません。

身に覚えのないログインがあれば、パスワードを変更します。**他のログインを解除** でほかのブラウザーからログアウトできます。1 台だけ接続を解除するには、**マシン** からそのマシンを削除します。**すべてのマシンを失効** を選ぶと、ペアリング済みのマシンがすべて切断されます。作業を再開したり復旧コードを発行したりするには、それぞれ再ペアリングが必要です。確認のうえで、個別のセキュリティ記録も削除できます。ほかのブラウザーには、それぞれでそのイベントを確認するまで通知が届きます。

**セキュリティ** で **キー** を開くと、自分に代わって作業に署名するブラウザーとマシンを確認できます。新しいブラウザーを追加するには、すでに一覧にあるブラウザーで **参加待ち** を開きます。両方のブラウザーに表示された 12 文字の短いコードを照合し、一致する場合にだけ **追加** を選びます。使わなくなった鍵には **削除**、紛失した端末には **盗難として登録** を使います。マシンの鍵を削除すると、そのマシンも削除されます。マシンで鍵一覧のリセットを開始した場合は、マシン名を確認してからブラウザーで承認します。

## 忘れたパスワードを復旧する

1. ペアリング済みのマシンのターミナルで `sail recover` を実行します。船長 ID と、10 分間有効で 1 回だけ使える 8 文字の復旧コードが表示されます。同じマシンで新しいコードを取得すると、最初のコードは無効になります。
2. ログイン画面で **パスワードをお忘れですか?** を選びます。ターミナルに表示された船長 ID と **復旧コード** を入力します。画面のマシン名とペアリング日を確認してから、新しいパスワードを入力します。
3. 画面に表示された復旧手順に従います。マシンの経過時間は、最後にペアリングした時点または認証情報を修復した時点から数えます。

| 復旧に使うマシン | 2 段階認証 | 手順 |
| --- | --- | --- |
| ペアリングから 72 時間未満 | 設定を問わない | 認証アプリのコードがあっても、72 時間の復旧リクエストを送ります。 |
| ペアリングから 72 時間以上 | 無効、または有効にしてから 72 時間未満 | 復旧コードですぐにリセットできます。最近有効にした 2 段階認証は、復旧時に無効になります。 |
| ペアリングから 72 時間以上 | 有効にしてから 72 時間以上 | 認証アプリのコードを入力するとすぐにリセットでき、2 段階認証も維持されます。コードがない場合は、72 時間の復旧リクエストを送ります。 |

待つ必要がある場合は **72時間待機の復旧を申請** を選び、復旧画面に表示される時刻に従います。ログイン済みの端末に通知が届きます。そのいずれかで **今回の復旧を取り消す** を選べます。ログインに成功した場合もリクエストは取り消されます。リセットが反映されたら、新しいパスワードでログインします。待機を伴う復旧では 2 段階認証がリセットされます。

復旧後は **ペアリング日時** の表示を **マシン** で確認し、身に覚えのないマシンを削除します。**セキュリティ** で 2 段階認証を再び有効にできます。

## ログアウトまたはアカウントを削除する

**サインアウト** を **自分** で選ぶと、このブラウザーのセッションが終了します。アカウントを閉じるには **アカウントを削除** を選び、対象のチームとマシンを確認します。パスワードを入力して確定し、2 段階認証が有効なら認証アプリのコードも入力します。削除を申請すると、各端末がログアウトし、マシンの認証が取り消され、サブスクリプションが解約されます。7 日以内にログインすれば申請を取り消せます。この間はマシンの認証が取り消されているため、パスワードを復旧できません。期限を過ぎるとアカウントが削除され、その番号は使えなくなります。

## うまくいかないとき

- 15 分以内に 5 回ログインに失敗すると、既定では 15 分間ロックされます。表示される時間まで待ちます。認証アプリのコードは 1 回しか使えません。使った直後なら次のコードを待ちます。
- ブラウザーでの確認が期限切れになった場合や、別の数字をタップした場合は、ログインをやり直します。表示されるコード認証も利用できます。新しいログイン用コードは `sail confirm`、新しいパスワード復旧コードは `sail recover` で取得します。
- マシンが復旧コードを発行できない場合は、アカウントにペアリング済みの別のマシンを試します。有効な認証情報を持つマシンがなければ、アカウントは復旧できません。新しい船長 ID を登録します。
