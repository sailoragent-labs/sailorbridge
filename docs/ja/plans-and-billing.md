# プランと請求

プランによって、すべてのチームとマシンで同時実行できる Agent の数が決まります。無料は 3、Pro は 15、Max は 60 の Agent を同時実行できます。モデルのアカウントは自分で用意します。登録時に短い船長 ID や特別な番号を買うこともできます。この買い切り購入はプランとは別です。[現在の料金](https://www.sailorbridge.com/#pricing)

## サブスクリプションまたは 1 か月分を購入する

1. **自分** から **サブスクリプション** を開きます。**同時実行の上限** に現在の上限が表示されます。
2. **アップグレード** を選びます。継続して支払うには **毎月自動更新するサブスクリプション**、1 回だけ支払うには **1か月分を購入** を選びます。どちらも、選んだプランの Agent 上限が適用されます。
3. 希望するプランの価格が表示された項目を選びます。アプリ内で決済画面が開きます。表示された支払い方法から選んで、支払いを済ませます。価格付きの項目を選ぶ前に、プランの選択画面で比較できます。
4. **サブスクリプション** に戻ってプランと上限を確認します。サブスクリプションでは **次回の請求**、1 か月分の購入では **終了日** が表示されます。

## 1 か月延長する

1 回の購入で、UTC を基準に暦上の 1 か月間利用できます。翌月に同じ日付がない場合は、その月の末日に期限が切れます。最後の 3 日間は期限が近いことをアプリが通知します。

同じプランを延長するには **1か月延長** を選びます。期限前に支払うと、既存の終了日に 1 か月が追加されます。期限を過ぎると無料に戻り、次に購入したプランは支払日から始まります。別の 1 か月プランにする場合は、現在のプランが終わるまで待ちます。

## サブスクリプションや支払い方法を変更する

- Pro と Max を切り替えるには、有効なサブスクリプションを開いて、もう一方のプランを選びます。プレビューには当期の請求額または差し引き額と、次回の請求日と金額が表示されます。**プラン変更を確定** を選んで進みます。変更が確定すると、新しい上限が画面に表示されます。
- 支払い方法を変えるには、**支払い方法を更新** を選び、決済画面に新しい情報を入力します。有効なサブスクリプションでは、この更新に料金はかかりません。**支払い失敗** が表示された場合は **支払い方法を更新して未払い分を支払う** を使います。決済画面に支払う未払い額が表示されます。プランを変える前に未払い分を支払います。
- 支払いを確認するには **支払い履歴** を開きます。直近 30 件の記録を確認できます。金額が 0 より大きい支払い済みの項目で **請求書** を選びます。リンクの有効期限は 1 時間です。

## サブスクリプションを解約または再開する

**サブスクリプションを解約** を選び、続けて **解約を確定** を選びます。確定後に表示される **解約済み(今期で終了)** は、表示された終了日まで有料プランの上限を使えることを示します。終了日前に **解約を取り消す** を選ぶと、追加請求なしで元の請求サイクルを維持できます。プランを変更するには、先に解約を取り消します。

サブスクリプションが **一時停止中** と表示されている場合は **サブスクリプションを再開** を選び、確認内容を読んでから **再開を確定** を選びます。再開すると、元のプランで新しい期間の全額がすぐに請求されます。返金条件と申請方法は[返金ポリシー](https://www.sailorbridge.com/refund.html)を確認してください。

## 登録時に船長 ID を購入する

1. **登録へ** を選び、希望する番号を正確に入力します。空いている 3～5 桁の ID と、3～8 桁の特別な番号には買い切り料金がかかります。通常の 6～8 桁の ID と 9～11 桁の ID はすべて無料です。使用済みなら別の番号に変更して確認します。番号を調べるだけでは注文されません。
2. 有料の番号は、その ID の購入操作を選びます。最初の取り置きは 15 分間です。決済を開始すると、支払いを済ませるまで、最初の取り置きから最大 24 時間その番号が確保されます。
3. **引き換えリンク** をコピーまたはダウンロードして、安全な場所に保管します。同じ支払いに戻るときや、別の端末で登録を完了するときに使えます。支払いを確認できたら、パスワードを設定し、年齢の確認と利用規約への同意を済ませて登録を完了します。購入した番号を 30 日間登録しなければ、全額が自動で返金されます。

## うまくいかないとき

- 決済画面を閉じたり更新したりした場合は、同じプランと購入方法に戻り、未払いの注文を再開します。支払いの確認中は、そのまま待つか、**更新** を **サブスクリプション** で選びます。ID の購入では **支払い状況を確認** を使うか、**引き換えリンク** を開き直します。確認が終わるまでは元の注文を使います。
- 2 件目の購入ができない場合は、**サブスクリプション** で現在のプランを管理するか、開始した決済に戻ります。請求の問題でサポートが必要なら、[非公開でサポートに問い合わせます](https://www.sailorbridge.com/contact.html)。
- サブスクリプションの全額返金が承認された場合やチャージバックがあった場合、アカウントは無料に戻ります。*登録済みの番号*が返金またはチャージバックされた場合は、表示された期限までに **再度支払って番号を残す** を使います。既定の猶予期間は 14 日間です。期限を過ぎるとアカウントを使えなくなり、サブスクリプションは解約されます。
