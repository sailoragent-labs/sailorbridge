# チームメモリ

チームメモリには、**リーダー** とワーカーが今後の作業で使う決定、取り決め、修正内容を保存します。各項目にはタイトル、本文、出典、`#6` のような番号があります。項目は 1 つのチームに属し、他のチームや友だちは閲覧できません。

## 覚えておくことを記録する

チームチャットで、何をいつ使うために覚えるか伝えます。たとえば「インストール例はセットアップガイドに置くと覚えてください。インストールコマンドを変更するときに使ってください」と伝えます。**リーダー** が記録した内容を知らせます。チームチャットの **その他の操作** メニューを開いて **チームメモリ** を選ぶと、項目を確認できます。タイトルを開くと、全文と最後に変更した人が表示されます。

## 項目を探してチャットで使う

**検索** を **チームメモリ** から開きます。タイトルや本文に含まれる言葉を入力します。テキスト検索ではすべての言葉が一致する必要があり、最初のページには意味の近い項目も最大 3 件表示される場合があります。通常の一覧ではピン留めした項目が先頭に表示されます。

番号が分かる場合、`#6` で検索すると項目 6 だけが表示されます。`6` で検索するとテキストの一致も表示されます。項目を開き、**チャットへ** を選びます。入力欄に `/memory #6` が入ります。質問や訂正を追加して送ります。

## 項目を編集、ピン留め、ロック、削除する

- 項目を開いて **本文** を変更し、**保存** を選びます。**History** には直近 10 版が表示されます。変わる可能性のある事実では、**Observed** と **Expires** を確認します。**Expired** の項目も読めるので、記載内容が今も当てはまるか確認します。
- **ピン留め** をオンにすると、指示が **リーダー** とワーカーに渡す資料に含まれます。項目にはチームのピン留めの使用量が表示されます。ピン留めしたタイトルと本文は合わせて 8 KiB までです。
- 自分だけが変更または削除できるようにするには、**変更不可** をオンにします。ピン留めだけなら、Agent は引き続き項目を編集できます。ロックした項目はウェブで自分で編集できます。
- **削除** を選んで確認すると、項目が完全に削除されます。番号は再利用されません。

## チームメモリを整理する

チームチャットで `/memory-tidy` を送ります。作業では項目を確認し、残すべきものに印を付け、関連項目をまとめ、今後使わない項目を削除します。**納品レポート** を開くと、行った操作と判断が必要な点を確認できます。作業でロックされた項目の削除や統合が提案されても、その項目は残ります。

確認する項目があると、チームごとに直近 24 時間に最大 1 回、自動整理が実行されます。依頼または予約したときだけ実行するには、**チームのフロー** で `memory-tidy` を選び、**自動整理** をオフにします。

## うまくいかないとき

- ピン留めで 8 KiB を超える場合は拒否されます。別の項目のピン留めを解除するか、ピン留めした文章を短くしてから試します。
- 操作中に誰かが項目を編集した場合は、最新の本文が表示されます。読み直してから訂正を反映します。
- 2 件の更新で同じタイトルが使われた場合、同じ作成者からの訂正は直接反映されることがあります。それ以外の場合、確認レベルが高い情報か、同じレベルなら観測が新しい情報で解決できることがあります。判断が必要な場合は **未解決の競合** と表示され、現在の本文が保持されます。項目を開いて事実を確かめ、正しい文面を保存します。ロックされた項目は自分で判断する必要があります。
- **リーダー** が記憶できなかったと報告したら、覚えてほしい内容をもう一度伝えます。項目がロックされているため Agent による変更が拒否されたら、**チームメモリ** で自分で変更します。
