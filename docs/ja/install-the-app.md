# アプリをインストールする

スマートフォンやパソコンでは、SailorBridge を Webアプリとしてインストールすることをおすすめします。専用のアイコンから、ブラウザーのタブやアドレスバーがない独立したウインドウで、通常のアプリと同じように開けます。

## iPhone または iPad の Safari

1. Safari で[アプリ](https://app.sailorbridge.com)を開きます。
2. **共有**ボタン（四角に上向き矢印）をタップします。表示されていない場合は、Safari のページメニューを先に開きます。
3. **ホーム画面に追加**を選びます。Webアプリとして開く設定が表示されたらオンにし、**追加**をタップします。ホーム画面のアイコンから SailorBridge を開きます。

iOS 16.4 以降の iPhone でプッシュ通知を受け取るには、ホーム画面にインストールしたアプリが必要です。アプリを開き、設定で **通知** をオンにして、確認画面で許可します。

## Android の Chrome

1. Chrome で[アプリ](https://app.sailorbridge.com)を開きます。
2. 三点メニューで **インストールしてショートカットを作成**、**インストール** の順に選びます。アプリのインストールやホーム画面への追加がメニューに直接表示される場合は、そこからインストールできます。
3. インストールを確定し、アイコンから SailorBridge を開きます。

## パソコンの Chrome または Edge

1. Chrome または Edge で[アプリ](https://app.sailorbridge.com)を開きます。
2. アドレスバーのインストールアイコンをクリックするか、ブラウザーのメニューから SailorBridge をアプリとしてインストールします。
3. インストールを確定し、アプリのアイコンから SailorBridge を開きます。

## Mac の Safari

1. macOS Sonoma 14 以降の Safari で[アプリ](https://app.sailorbridge.com)を開きます。
2. **ファイル → Dockに追加**の順に選びます。
3. **追加**をクリックし、Dock から SailorBridge を開きます。

## インストール後

アプリを初めて開くときに、再度ログインが必要になることがあります。Safari でインストールした場合など、アプリが独自のブラウザーデータを使うときは、SailorBridge はそのアプリを同じアカウントの新しいブラウザーとして扱います。[ログインして新しいブラウザーを確認する](account-and-security.md#ログインして新しいブラウザーを確認する)を参照してください。このブラウザーのキーの追加を求められた場合は、[アクティビティと端末の鍵を確認する](account-and-security.md#アクティビティと端末の鍵を確認する)を参照してください。

削除するには、iPhone や iPad ではホーム画面から削除し、Android ではアプリの設定から、Chrome や Edge ではブラウザーからアンインストールします。Mac の Safari で追加した場合は、ホームフォルダ内の「アプリケーション」フォルダから削除します。
