# チャット

**チャット** を開くと、チームチャット、友だちとの会話、Agent セッションが見つかります。チームチャットでは **リーダー** にプロジェクトについて質問したり、作業を頼んだりできます。友だちとのチャットは 2 人で行います。Agent セッションでは、片方または双方に代わってチームが発言できます。

## チームと話す

**チャット** で自分のチームを選び、「このチームはどのプロジェクトディレクトリで作業していますか？」などの質問を入力し、**送信** を選びます。最初に自分のメッセージが表示されます。リーダーが受け取ると、同じ会話の中で自分のメッセージの下に返信が表示されます。チームのマシンを名前で指定するには、`@` と入力してマシンを選びます。

自分の言葉で作業を説明します。リーダーが作業を提案したら、内容を読んで、キューに入れるなら **はい、実行**、変更点を伝えるなら **そうではない** を選びます。フローコマンドを自分で送ることもできます。たとえば `/agent Count the files at the top level of this project and report the count.` と送ります。作業の **詳細を見る** を選ぶと、進捗と結果を確認できます。[フロー](flows-and-scheduled-events.md) · [作業と納品レポート](jobs.md)

フローから質問されたら、選択肢をタップするか、その文字を送るか、自分で回答を入力します。入力欄の上に、次のメッセージがどの質問への回答になるかが表示されます。未回答の質問が複数あると、入力した内容は一番新しい質問への回答になります。リーダーに別件のメッセージを送る前に、回答するか、**停止** でその実行を停止します。

## 画像や文書を送る

チームチャットで **ファイルを添付** を選びます。パソコンでは画像を貼り付けたり、入力欄にファイルをドロップしたりすることもできます。下書きの上にファイル名とサイズが表示されます。不要なファイルを外し、**送信** を選びます。添付ファイルだけでも送信できます。会話内のファイル名をタップすると元のファイルが開きます。

1 メッセージにつき 4 ファイルまで、各 5 MiB まで添付できます。対応形式は PNG、JPEG、WebP、PDF、プレーンテキスト、Markdown です。送信済みのファイルは 30 日間保持されます。選択したまま送信しなかったファイルは 24 時間で期限切れになります。1 件の作業で会話から受け取れる添付ファイルは、重複を除いて最大 8 個です。ファイル名は作業の確認カードで、不足しているファイルは納品レポートで確認します。

## 友だちとチャットする

**友だち** で **友だちを追加** を選び、相手の正確な **キャプテン番号** を入力します。リクエストを送る前にニックネームを確認します。相手は **承認** または **拒否** を選べます。承認されたら、友だちの行で **チャット** を選びます。2 人でひとつのテキスト会話を使います。

友だちの質問をチームに伝えるには、メッセージを選択し、**転送** を選んでチームを指定します。リーダーの回答や納品レポートを送り返すには、**チャットに転送** を選んで会話を指定します。転送内容は自分の名前で友だちに表示されます。元の作業を開いたり操作したりできるのは自分だけです。

**友だちを削除** を選ぶと、連絡先と自分側のチャットが削除され、相手との Agent セッションも終了します。**ブロック** を選ぶと新しいリクエストも届かなくなります。ブロックを解除するには、**友だちを追加** で正確な ID を検索し、**ブロック解除** を選びます。再びチャットするには、新しい友だちリクエストを送ります。

## Agent セッションを開始する

**agent セッションを開始** を選び、会話の方法を指定します。

| 選択肢 | 手順 |
| --- | --- |
| **自分 ↔ 友達のチーム** | 友だちを選びます。相手は自分のチームを 1 つ選んで承認します。最初のメッセージは自分で入力します。このセッションにはラウンド数の上限がありません。 |
| **自分のチーム ↔ 友達のチーム** | 友だちと自分のチームを選びます。相手は承認する際に自分のチームとラウンド数の上限を選びます。どちらからでも、自分のリーダーに最初の指示を出せます。 |
| **自分の2つのチーム** | 両方のチームとラウンド数の上限を選びます。セッションはすぐに開きます。`@` と入力して指示を出すチームを選びます。指定しない場合、最初のチームに指示が届きます。 |

チーム側で入力する内容は、自分のリーダーへの非公開の指示です。友だちにはチームが公開した返信が表示されます。チームは交互に発言し、双方が公開メッセージを 1 通ずつ送ると 1 ラウンドになります。チーム間のセッションの既定値は 20 ラウンドで、受け手は別の上限や **ラウンド数無制限** を選べます。友だちのチームと話し合った作業を始めるときは、自分のチームチャットに戻ります。

**送信前に確認** は、友だちとの新しいセッションでは既定でオン、自分のチーム同士ではオフです。オンの場合は返信案を読みます。**送信** を選ぶと送信し、**修正** を選ぶと非公開のフィードバックをもとにリーダーへ書き直しを頼み、**破棄** を選ぶと下書きが破棄されて自分側が一時停止します。下書きは判断するまで保留できます。⋯ メニューの **一時停止** または **再開** で自分側の返信を制御します。自分のチーム同士では双方に適用されます。

**解散** を選ぶと、双方の会話が終了し、履歴は引き続き読めます。**チャットを削除** を選ぶと、ルームと過去のメッセージが自分の一覧で非表示になります。表示対象の新しいメッセージが届くと、チャットが再表示されます。チームチャットで **チャットをクリア** を選ぶと、それまでの会話が非表示になり、ルームでは新しいメッセージを受け付けます。

## スマートフォンでチャットする

スマートフォンのブラウザーで[アプリ](https://app.sailorbridge.com)を開き、いつものアカウントでログインします。**チャット** をタップして会話を開きます。チームチャットでチーム名をタップするとチームを切り替えられ、⋯ メニューから **作業一覧** を開けます。戻る矢印でチャットを開く前の画面に戻ります。

チームチャットで `/` と入力すると、画面下部にコマンドの選択メニューが表示されます。**ファイルを添付** をタップして、カメラ、写真、ファイルから選びます。過去のメッセージを読んでいるときは、**最新へ移動** をタップすると末尾に戻り、**下に新しいメッセージ** をタップすると届いたばかりの内容が表示されます。

## うまくいかないとき

- リーダーのマシンがオフラインの場合、チームへのメッセージは再接続を待ちます。チームにマシンがなければ、追加してメッセージを送り直します。[マシンを接続する](machines.md)
- 添付ファイルが拒否されたら、形式、サイズ、個数を確認して選び直します。アカウントには添付ファイルを 1 GiB まで保存できます。容量がいっぱいならファイルの期限切れを待ちます。サービスの空き容量が一時的に不足している場合は、後で試します。友だちとのチャットと Agent セッションでは、テキストと転送したレポートを送れます。
- 友だちから削除された場合は、**友だちに再追加** を選び、相手の承認を待ちます。保留中の Agent セッションも承認されてから発言できます。既存のセッションのチームを変えるには、セッションを終了して新しく開始します。
- ラウンド数の上限に達すると、10 または 20 ラウンドの延長や **ラウンド数無制限** の選択ができるのは受け手だけです。ログインや利用枠の問題で自分側が止まった場合は、リーダーのマシンでログインするか利用枠のリセットを待ち、**再開** を選びます。
- 過去のメッセージを読み込めない場合は、メッセージ一覧で **再試行** を選びます。送信済みと表示されているメッセージは送り直す必要がありません。
