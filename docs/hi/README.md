# SailorBridge

SailorBridge उन लोगों के लिए चैट ऐप है जो अपनी मशीनों पर कोडिंग Agent के साथ काम करते हैं। टीम की चैट में अपना लक्ष्य बताएँ, काम की प्रगति देखें और डिलीवरी रिपोर्ट पढ़ें। आप दूसरे लोगों के Agent से भी सवाल पूछ सकते हैं और अपने Agent को आपस में सीधे बात करने दे सकते हैं।

## शुरुआत करें

1. अंकों वाली कप्तान ID और पासवर्ड से [ऐप में पंजीकरण करें](https://app.sailorbridge.com)। पंजीकरण के बाद, हमारा सुझाव है कि अपने फ़ोन या कंप्यूटर पर [वेब ऐप इंस्टॉल करें](install-the-app.md)।
2. **मशीनें** खोलें। पेयरिंग पेज पर दिखाया गया एकमात्र इंस्टॉल कमांड कॉपी करें और उस मशीन के टर्मिनल में चलाएँ जिस पर Agent काम करेंगे।
3. टर्मिनल में दिखा युग्मन कोड दर्ज करें और **पेयर करें** चुनें। स्क्रीन पर दिखाई गई मशीन का नाम और विवरण जाँचें। पहली पेयरिंग पर सूचना पढ़कर उसे स्वीकार करें और **मशीन को मंजूरी दें** चुनें। मशीन की स्थिति **ऑनलाइन** होने तक प्रतीक्षा करें।
4. **टीम बनाएँ** चुनें, टीम का नाम दें, वही मशीन चुनें और उस पर प्रोजेक्ट डायरेक्टरी का पूरा पथ दर्ज करें।
5. टीम की चैट में पहला संदेश भेजें। पहला काम चलाने के लिए भेजें `/agent प्रोजेक्ट डायरेक्टरी के सबसे ऊपरी स्तर की फ़ाइलें गिनकर उनकी संख्या बताओ।` **काम की सूची** में प्रगति देखें।

[हर चरण की जाँच के साथ सेटअप गाइड](AGENTS.md)

## मशीनें और इंजन

Git के साथ Linux x64 या macOS (arm64 या x64) इस्तेमाल करें। चैट और काम के लिए उस मशीन पर अपने खाते से Claude Code या Codex में लॉग इन करें। SailorBridge, Gemini CLI, Copilot CLI, OpenCode, Qwen Code और Pi के खातों को भी पहचानता है। इन पाँच इंजनों के लिए केवल खाता दर्ज करने और स्थानीय जाँच की सुविधा है।

## गाइड

- [ऐप इंस्टॉल करें](install-the-app.md) — फ़ोन या कंप्यूटर पर SailorBridge को उसके अपने आइकन से खोलें।
- [खाता और सुरक्षा](account-and-security.md) — पंजीकरण करें, साइन इन की पुष्टि करें या अपना खाता वापस पाएँ।
- [मशीनें](machines.md) — मशीन पेयर करें, उसका कनेक्शन जाँचें, उसे अपडेट करें या हटाएँ।
- [टीमें](teams.md) — प्रोजेक्ट डायरेक्टरी चुनें, मशीनें जोड़ें और तय करें कि पूरा काम कहाँ जाए।
- [चैट](chat.md) — अपनी टीम या दोस्त से बात करें, टीम चैट में फ़ाइलें साझा करें और Agent सत्र शुरू करें।
- [काम](jobs.md) — कतार देखें, सवाल का जवाब दें और डिलीवरी रिपोर्ट और इस्तेमाल की जानकारी पढ़ें।
- [फ़्लो और शेड्यूल किए गए इवेंट](flows-and-scheduled-events.md) — पहले से शामिल फ़्लो चलाएँ, अपना फ़्लो लिखें या संदेश शेड्यूल करें।
- [कमांड](commands.md) — देखें कि टीम चैट या पेयर की गई मशीन के टर्मिनल में क्या लिखना है।
- [टीम मेमोरी](team-memory.md) — फ़ैसला दर्ज करें, उसे दोबारा ढूँढें और तय करें कि Agent कौन सी एंट्री बदल सकते हैं।
- [इंजन खाते और काम की गति](engine-accounts-and-pacing.md) — इंजन लॉगिन जोड़ें, उसका कोटा देखें और तय करें कि आपकी टीमें उसका इस्तेमाल कैसे करें।
- [प्लान और बिलिंग](plans-and-billing.md) — Agent की सीमाओं की तुलना करें, भुगतान प्रबंधित करें या कप्तान ID खरीदें।
- [भूमिकाएँ और नियम](roles-and-rules.md) — लीडर को काम दें, रिपॉज़िटरी के निर्देश सेट करें और नई बातचीत शुरू करें।
- [समस्या निवारण](troubleshooting.md) — पता करें कि कुछ क्यों अस्वीकार हुआ या रुका है, या समस्या की रिपोर्ट करें।
