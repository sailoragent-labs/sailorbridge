# SailorBridge 설정 가이드

## 1. 머신 준비하기

직접 관리하는 Linux x64 또는 macOS(arm64 또는 x64) 머신에 Git과 Claude Code 또는 Codex 중 하나를 설치합니다. 본인 계정으로 엔진에 로그인하고 팀이 사용할 프로젝트 디렉터리를 정합니다.

**확인** — `git --version`과 선택한 엔진의 `claude --version` 또는 `codex --version`을 실행하면 버전이 각각 표시됩니다. 설치한 엔진에 아직 로그인하지 않았다면 머신에서 `claude login` 또는 `codex login`을 실행하세요. 페어링을 먼저 해도 됩니다. 채팅이나 작업을 시작하기 전에는 엔진에 로그인하세요.

## 2. 브라우저에서 가입하기

[앱](https://app.sailorbridge.com)을 열고 **가입하기**를 선택합니다. 이 예제에서는 사용 가능하고 무료로 표시되는 숫자 선장 ID를 입력하고 비밀번호를 설정한 뒤 연령을 확인하고 약관에 동의합니다.

**확인** — 앱에 접속한 뒤 **머신** 페이지를 열 수 있습니다.

## 3. 설치 명령 실행하기

**머신**에서 **새 머신 페어링**을 엽니다. 화면에 표시된 설치 명령 하나를 복사하여 1단계의 머신에서 실행합니다. `sail`이 설치되고 페어링이 자동으로 시작됩니다.

**확인** — 터미널에 8자리 페어링 코드와 남은 시간이 표시됩니다. 코드가 만료되면 `sail login`으로 새 코드를 받습니다.

- **같은 주소에 이미 페어링한 경우** — `sail host status`로 연결 상태를 확인합니다. 연결되어 있으면 5단계로 진행하세요. 같은 주소에서 서비스를 복구하려면 `sail login`을 실행합니다. 기존 인증 정보로 서비스가 다시 시작됩니다.
- **주소가 다른 경우(`origin_mismatch`)** — 주소를 바꾸려면 `sail uninstall`을 실행한 뒤 연결할 앱의 머신 페이지에서 설치 명령을 복사해 다시 실행합니다. 제거하면 작업용 복사본을 포함한 SailorBridge의 로컬 데이터가 삭제됩니다.

## 4. 머신 승인하기

브라우저의 페어링 페이지에 코드를 입력하고 **페어링**을 선택합니다. 머신 이름과 **키 코드**가 터미널에 표시된 값과 일치하는지 확인합니다. 첫 페어링에서는 `sail`을 실행하는 사용자의 권한에 관한 안내를 읽고 동의한 뒤 **머신 승인**을 선택합니다.

**확인** — **머신** 페이지에서 **온라인** 상태가 될 때까지 기다립니다. 터미널에도 페어링되었고 온라인이라는 메시지가 표시됩니다.

## 5. 팀 만들기

**팀 만들기**를 선택합니다. 팀 이름을 정하고 온라인 머신을 선택한 뒤 **프로젝트 디렉터리**에 그 머신의 절대 경로를 입력합니다. 디렉터리가 없으면 처음 사용할 때 생성됩니다. **결과 대상**에서 기본값인 **자동 병합**을 유지하면 변경 사항을 원격 메인 브랜치에 병합합니다. 작업마다 별도 브랜치에 푸시해 검토하려면 **브랜치**를 선택합니다. 팀을 만듭니다.

**확인** — 새 팀에서 선택한 머신이 **온라인**으로 표시됩니다.

## 6. 첫 메시지 보내기

팀의 **채팅**을 열고 “우리 팀이 사용하는 프로젝트 디렉터리는 어디야?”라고 묻습니다.

**확인** — 같은 채팅에서 **리더**가 답합니다.

## 7. 첫 작업 완료하기

팀 채팅에서 `/agent 프로젝트 최상위 디렉터리의 파일 수를 세어서 알려 줘.`를 보냅니다. **⋯ → 작업 목록**에서 진행 상황을 확인합니다.

**확인** — 작업이 **완료** 상태로 표시됩니다. **납품 보고서**를 열어 파일 수를 확인합니다.
