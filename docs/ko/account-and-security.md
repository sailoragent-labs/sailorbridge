# 계정 및 보안

숫자로 된 **선장 ID**가 로그인 이름입니다. 닉네임이나 비밀번호를 변경하거나 다른 브라우저를 사용해도 계정의 선장 ID는 그대로입니다. 로그인할 수 있을 때 직접 관리하는 머신을 페어링하세요. 비밀번호를 잊었을 때 페어링된 머신이 필요합니다.

## 계정 만들기

1. [앱](https://app.sailorbridge.com)을 열고 **가입하기**를 선택합니다. 원하는 3~11자리 번호를 입력합니다. **이미 소유권이 주장됨**이라고 표시되면 다른 번호를 입력해 확인합니다.
2. 페이지에 표시되는 번호 정보를 확인합니다. 일반 6~8자리 ID와 모든 9~11자리 ID는 무료입니다. 더 짧은 ID와 최대 8자리의 특수 패턴 번호는 한 번 결제해야 합니다. 유료 번호라면 다른 기기에서도 가입을 마칠 수 있도록 결제할 때 **교환 링크**를 저장합니다. [요금](https://www.sailorbridge.com/#pricing)
3. 비밀번호를 설정하고 다시 입력합니다. 기본 제공 아바타를 선택하거나 이니셜을 그대로 사용할 수 있습니다. 나이를 확인하고 **서비스 약관**에 동의한 뒤 **가입**을 선택합니다. 앱에 로그인됩니다. [첫 머신 페어링](machines.md)

## 로그인하고 새 브라우저 확인하기

**선장 ID**를 입력하고 **다음**을 선택한 뒤 **비밀번호**를 입력하고 **로그인**을 선택합니다. 페어링된 머신이 있으면 SailorBridge가 새 브라우저에서 자동으로 본인 확인을 요청합니다. 2단계 인증이 꺼져 있으면 이미 인식된 브라우저에서는 비밀번호만으로 로그인합니다. 페어링된 머신이 없고 2단계 인증도 꺼져 있으면 새 브라우저에서도 비밀번호만으로 로그인할 수 있습니다. 선택 기능인 **2단계 인증**을 켜면 익숙한 브라우저에서도 로그인할 때마다 확인해야 합니다.

**본인 확인** 화면에서 제공되는 방법 중 하나를 사용합니다.

- **인증 앱 코드**를 선택하면 인증 앱에 현재 표시된 코드를 입력합니다.
- **머신 코드**를 선택하면 페어링된 머신의 터미널에서 `sail confirm` 명령을 실행합니다. 로그인 페이지에 8자 코드를 입력합니다.
- **브라우저 승인**을 선택하면 이미 로그인된 다른 익숙한 브라우저를 엽니다. 승인 창에서 로그인 페이지에 표시된 두 자리 숫자를 누릅니다. 직접 시작한 로그인만 승인하세요. 다른 사람이 시작했다면 **제가 아닙니다**를 선택합니다.

## 프로필 설정 및 로그인 보호

**나**를 엽니다. **닉네임**을 설정하고 갤러리에서 **아바타**를 선택할 수 있습니다. **언어**는 다음 채팅 차례나 작업부터 화면 표시와 답변에 적용됩니다. **답변 방식**에서 설명이 더 필요하면 **초보자**를, 짧은 답변을 원하면 **전문가**를 선택합니다.

**보안**을 열고 **2단계 인증**을 선택합니다. **켜기**를 선택하고 비밀번호를 확인한 뒤 인증 앱으로 QR 코드를 스캔합니다. 현재 코드를 입력하고 **확인하고 켜기**를 선택합니다. 끄려면 **2단계 인증 끄기**를 선택하고 비밀번호와 새 코드를 입력합니다.

비밀번호를 바꾸려면 **현재 비밀번호**, **새 비밀번호**, **새 비밀번호 확인** 항목을 **보안**에서 입력합니다. 2단계 인증이 켜져 있으면 인증 앱 코드도 입력합니다. 변경하면 현재 브라우저는 로그인 상태로 유지되고 다른 세션에서는 로그아웃됩니다.

## 활동 및 기기 확인하기

**나**를 열고 **보안**에서 **최근 보안 기록**을 엽니다. 최근 90일의 기록이 표시됩니다. 새 브라우저에서 로그인에 성공하면 본인의 로그인인지 확인을 요청합니다. **제가 맞습니다** 또는 **제가 아닙니다**를 선택합니다. 확인 기록은 브라우저마다 따로 관리됩니다. 실패한 로그인은 승인 요청 없이 목록에 표시됩니다.

본인이 한 로그인이 아니면 비밀번호를 변경합니다. **다른 세션 로그아웃**을 선택하면 다른 브라우저와 앱에서 로그아웃되고 현재 세션은 유지됩니다. 머신 한 대의 연결만 끊으려면 **머신**에서 해당 머신을 제거합니다. **모든 머신 취소**를 선택하면 페어링된 모든 머신의 연결이 끊어집니다. 각 머신에서 작업하거나 복구 코드를 발급하려면 다시 페어링해야 합니다. 확인 후 보안 기록 하나를 삭제할 수도 있습니다. 다른 브라우저에서는 각각의 알림에서 해당 이벤트를 확인할 때까지 알림을 받습니다.

**보안**에서 **기기**를 열면 앱과 페어링된 머신을 확인할 수 있습니다. 기기를 선택한 뒤 **제거**를 누르면 해당 기기에서 새 작업을 승인할 수 없습니다. 앱은 로그아웃되고 머신은 연결이 해제됩니다. 기기를 잃어버렸다면 **분실 또는 도난**을 선택합니다. SailorBridge는 그 기기가 이전에 승인한 내용도 받아들이지 않습니다.

## 잊어버린 비밀번호 복구하기

1. 페어링된 머신의 터미널에서 `sail recover`를 실행합니다. 선장 ID와 10분 동안 한 번만 사용할 수 있는 8자 복구 코드가 표시됩니다. 같은 머신에서 코드를 다시 받으면 기존 코드는 무효가 됩니다.
2. 로그인 페이지에서 **비밀번호를 잊으셨나요?** 항목을 선택합니다. 터미널에 표시된 선장 ID와 **복구 코드**를 입력합니다. 페이지에서 머신 이름과 페어링 날짜를 확인한 뒤 새 비밀번호를 입력합니다.
3. 화면에 표시된 복구 절차를 따릅니다. 머신의 페어링 경과 시간은 가장 최근에 페어링했거나 인증 정보를 복구한 시점부터 계산합니다.

| 복구에 사용하는 머신 | 2단계 인증 | 진행 방법 |
| --- | --- | --- |
| 페어링한 지 72시간 미만 | 모든 설정 | 인증 앱 코드가 있어도 72시간 복구 요청을 제출합니다. |
| 페어링한 지 72시간 이상 | 꺼져 있거나 켠 지 72시간 미만 | 복구 코드로 즉시 재설정합니다. 최근에 켠 2단계 인증은 복구 시 꺼집니다. |
| 페어링한 지 72시간 이상 | 켠 지 72시간 이상 | 인증 앱 코드를 입력하면 즉시 재설정할 수 있고 2단계 인증도 유지됩니다. 코드가 없으면 72시간 복구 요청을 제출합니다. |

기다려야 한다면 **72시간 대기 복구 신청**을 선택하고 복구 페이지에 표시된 시간을 따릅니다. 로그인된 기기에 알림이 전송됩니다. 그중 한 기기에서 **이번 복구 취소**를 선택할 수 있습니다. 로그인에 성공해도 요청이 취소됩니다. 재설정이 적용되면 새 비밀번호로 로그인합니다. 대기 후 복구하면 2단계 인증이 초기화됩니다.

복구 후 **페어링 일시** 항목을 **머신**에서 확인하고 모르는 머신은 제거합니다. **보안**에서 2단계 인증을 다시 켤 수 있습니다.

## 로그아웃 또는 계정 삭제하기

**로그아웃** 메뉴 항목을 **나**에서 선택해 현재 브라우저의 세션을 종료합니다. 계정을 닫으려면 **계정 삭제**를 선택하고 영향을 받는 팀과 머신을 살펴본 뒤 비밀번호로 확인합니다. 2단계 인증이 켜져 있으면 인증 앱 코드도 입력합니다. 삭제를 요청하면 기기에서 로그아웃되고 머신의 권한이 취소되며 구독도 해지됩니다. 7일 이내에 로그인하면 요청을 취소할 수 있습니다. 이 기간에는 머신 권한이 취소된 상태라 비밀번호를 복구할 수 없습니다. 기한이 지나면 계정이 삭제되고 해당 번호는 더 이상 사용할 수 없습니다.

## 문제가 생겼을 때

- 15분 안에 5번 로그인에 실패하면 기본 15분 동안 잠깁니다. 표시된 시간까지 기다립니다. 인증 앱 코드는 한 번만 사용할 수 있습니다. 이미 썼다면 다음 코드를 기다립니다.
- 브라우저 확인이 만료됐거나 잘못된 숫자를 눌렀다면 다시 로그인합니다. 화면에 제시된 코드 인증 방법을 사용할 수도 있습니다. 새 로그인 코드를 받으려면 `sail confirm`를, 새 비밀번호 복구 코드를 받으려면 `sail recover`를 실행합니다.
- 머신에서 복구 코드를 발급할 수 없다면 계정에 페어링된 다른 머신을 사용합니다. 유효한 인증 정보가 있는 머신이 없으면 계정을 복구할 수 없습니다. 새 선장 ID를 등록합니다.
