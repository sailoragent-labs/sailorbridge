# 앱 설치하기

휴대전화나 컴퓨터에서는 SailorBridge를 웹 앱으로 설치하는 것을 권장합니다. 전용 아이콘이 생기며, 브라우저의 탭과 주소 표시줄 없이 일반 앱처럼 별도의 창에서 열립니다.

## iPhone 또는 iPad의 Safari

1. Safari에서 [앱](https://app.sailorbridge.com)을 엽니다.
2. **공유** 버튼(위쪽 화살표가 있는 사각형)을 누릅니다. 버튼이 보이지 않으면 Safari의 페이지 메뉴를 먼저 엽니다.
3. **홈 화면에 추가**를 선택합니다. **웹 앱으로 열기**가 보이면 켠 뒤 **추가**를 누릅니다. 홈 화면 아이콘에서 SailorBridge를 엽니다.

iOS 16.4 이상을 사용하는 iPhone에서는 홈 화면에 설치한 앱에서만 푸시 알림을 받을 수 있습니다. 앱을 열고 설정에서 **알림**을 켠 뒤, 권한 요청이 표시되면 허용합니다.

## Android의 Chrome

1. Chrome에서 [앱](https://app.sailorbridge.com)을 엽니다.
2. 점 세 개 메뉴에서 **설치 및 바로가기 만들기**, **설치**를 차례로 선택합니다. 앱 설치나 홈 화면에 추가하는 옵션이 메뉴에 바로 표시되면 그 옵션으로 설치할 수도 있습니다.
3. 설치를 확인하고 아이콘에서 SailorBridge를 엽니다.

## 컴퓨터의 Chrome 또는 Edge

1. Chrome 또는 Edge에서 [앱](https://app.sailorbridge.com)을 엽니다.
2. 주소 표시줄의 설치 아이콘을 클릭하거나 브라우저 메뉴에서 SailorBridge를 앱으로 설치하는 옵션을 선택합니다.
3. 설치를 확인하고 앱 아이콘에서 SailorBridge를 엽니다.

## Mac의 Safari

1. macOS Sonoma 14 이상이 설치된 Mac에서 Safari로 [앱](https://app.sailorbridge.com)을 엽니다.
2. **파일 → Dock에 추가**를 선택합니다.
3. **추가**를 클릭한 뒤 Dock에서 SailorBridge를 엽니다.

## 설치한 뒤

앱을 처음 열면 다시 로그인해야 할 수 있습니다. Safari에서 설치한 경우처럼 앱이 별도의 브라우저 데이터를 사용하면 SailorBridge는 해당 앱을 이 계정의 새 브라우저로 처리합니다. [로그인하고 새 브라우저 확인하기](account-and-security.md#로그인하고-새-브라우저-확인하기)를 참고하세요. 이 브라우저의 키를 추가하라는 메시지가 표시되면 [활동 및 기기 키 확인하기](account-and-security.md#활동-및-기기-키-확인하기)를 참고하세요.

앱을 삭제하려면 iPhone이나 iPad에서는 홈 화면에서 삭제하고, Android에서는 앱 설정에서, Chrome이나 Edge에서는 브라우저에서 제거합니다. Mac에서 Safari로 설치했다면 홈 폴더의 응용 프로그램 폴더에서 삭제합니다.
