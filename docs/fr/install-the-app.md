# Installer l’app

Nous vous recommandons d’installer SailorBridge comme app web sur votre téléphone ou votre ordinateur. Elle a sa propre icône et s’ouvre comme une app native, dans sa propre fenêtre, sans les onglets ni la barre d’adresse habituels du navigateur.

## iPhone ou iPad dans Safari

1. Ouvrez l’[application](https://app.sailorbridge.com) dans Safari.
2. Touchez **Partager** (le carré avec une flèche vers le haut). Si le bouton est masqué, ouvrez d’abord le menu de la page dans Safari.
3. Choisissez **Sur l’écran d’accueil**. Si **Ouvrir comme app web** apparaît, activez cette option, puis touchez **Ajouter**. Ouvrez SailorBridge depuis son icône sur l’écran d’accueil.

Sur iPhone avec iOS 16.4 ou une version ultérieure, seule l’app installée sur l’écran d’accueil peut recevoir des notifications push. Ouvrez-la, activez les **Notifications** dans les réglages, puis autorisez-les à l’invite.

## Android dans Chrome

1. Ouvrez l’[application](https://app.sailorbridge.com) dans Chrome.
2. Ouvrez le menu à trois points et choisissez **Installer et créer un raccourci**, puis **Installer**. Vous pouvez aussi installer l’app depuis l’option d’installation ou d’ajout à l’écran d’accueil si elle apparaît directement dans le menu.
3. Confirmez l’installation, puis ouvrez SailorBridge depuis son icône.

## Chrome ou Edge sur ordinateur

1. Ouvrez l’[application](https://app.sailorbridge.com) dans Chrome ou Edge.
2. Cliquez sur l’icône d’installation dans la barre d’adresse ou utilisez le menu du navigateur pour installer SailorBridge comme app.
3. Confirmez l’installation, puis ouvrez SailorBridge depuis l’icône de l’app.

## Safari sur Mac

1. Ouvrez l’[application](https://app.sailorbridge.com) dans Safari sous macOS Sonoma 14 ou une version ultérieure.
2. Choisissez **Fichier → Ajouter au Dock**.
3. Cliquez sur **Ajouter**, puis ouvrez SailorBridge depuis le Dock.

## Après l’installation

Vous devrez peut-être vous reconnecter la première fois que vous ouvrez l’app. Si l’app installée dispose de ses propres données de navigation, comme avec Safari, SailorBridge la considère comme un nouveau navigateur pour votre compte. Consultez [Se connecter et confirmer un nouveau navigateur](account-and-security.md#se-connecter-et-confirmer-un-nouveau-navigateur). Si l’app vous demande d’ajouter la clé de ce navigateur, consultez [Vérifier l’activité et les clés des appareils](account-and-security.md#vérifier-lactivité-et-les-clés-des-appareils).

Pour retirer l’app, supprimez-la de l’écran d’accueil sur iPhone ou iPad, désinstallez-la dans les paramètres des applications sur Android ou depuis Chrome ou Edge. Sur Mac, si vous l’avez installée avec Safari, supprimez-la du dossier Applications de votre dossier de départ.
