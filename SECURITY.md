# Report a security problem privately

Email [captain@sailorbridge.com](mailto:captain@sailorbridge.com). Do not open a public issue for a suspected vulnerability or a security incident.

Describe what you observed, where it happened, and who or what could be affected. Include the steps that led to it, the approximate time and time zone, and the product version if shown. A short, redacted example is enough.

Never send keys, tokens, pairing codes, passwords, payment details, or private source code. Remove them from any error messages or screenshots you share.
